# Manuel Noya Vázquez

Mi web personal: formación, experiencia en ciberseguridad, proyectos, publicaciones y actividades.

## Desarrollo

Sitio estático con HTML y CSS, sin dependencias ni proceso de compilación. Abrir `index.html` en el navegador o servir el directorio con un servidor estático.

## Archivos

- `index.html`: contenido y estructura de la web.
- `assets/css/style.css`: estilos y adaptación a distintos tamaños de pantalla.
- `assets/img/`: fotografía y favicon.
- `assets/docs/`: documentos disponibles para descarga pública.

## Publicación

Preparado para GitHub Pages. Los documentos privados y los certificados que solo se mencionan no se incluyen en este repositorio.
